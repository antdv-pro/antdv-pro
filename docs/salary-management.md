# 工资管理交互与数据契约

## 月度流程

打开财务月时按在职人员幂等生成工资草稿。工资模板提供固定工资和社保标准；月度工资表只直接录入考勤天数、加班补助和出差补助，其余项目由系统即时计算。

锁定前必须展示影响人数，并提示公司、姓名、岗位或出勤天数未完成的记录。锁定需要二次确认；服务端会拒绝已锁定、已发放、已归档等记录的删除、字段修改和状态回退，页面在失败时恢复本地修改。

## 状态口径

允许进入批量锁定的状态为 `草稿` 和 `待补录`。锁定后的状态只能沿工资审批与发放流程前进：`审批通过`、`已锁定`、`已发放`、`已作废`、`已归档`。工资记录不提供普通删除或直接回退入口。

## 页面状态

- 生成中：显示自动生成状态，禁用保存和锁定。
- 待补录：显示缺少人员或考勤数据的数量，允许返回补录。
- 空数据：显示当前筛选范围暂无数据，不显示“下降 100%”等比较趋势。
- 保存失败：保留筛选条件和输入，恢复可编辑状态并显示服务端错误。
